# Security policy

Wizza Media is local-first and sends no telemetry. It never circumvents DRM,
paywalls, subscriptions, geographic controls, bot protection, or technical
access controls. Browser permissions and provider capabilities are denied by
default. Credentials must eventually use Secret Service and never SQLite.

Do not include secrets, cookies, tokens, signed URLs, or personal media paths in
reports. Report vulnerabilities privately to the project maintainers.
